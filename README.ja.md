# 織叙-NexTale（NexTale）

> [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.md)

Python + Web UI で構築された AI 小説執筆ツール。複数の執筆モード（アウトライン / 即興 / 会話）、複数の AI プロバイダー接続、キャラクター写真分析、章の推敲・拡張、完結管理、ゴミ箱など、完全な小説執筆ワークフローをサポートします。

## 機能

### 執筆モード

| モード | 説明 |
|------|------|
| **アウトライン式** | まずあらすじ・世界観・章立てを生成し、その後章ごとに本文を執筆。長編の計画に最適。 |
| **即興式** | アウトライン不要。書きながら決めていき、「執筆ガイド」に沿って毎回1章ずつ生成。ひらめき重視の執筆向け。 |
| **会話モード** | IM チャットのようにストーリーを進行。AI は毎回500字以内を出力し、会話をいつでも正式な章に統合できます。 |

### 主な機能

1. **複数プロバイダー接続**：OpenAI 互換 API（OpenAI / DeepSeek / 智譜 GLM / Kimi / 通義千問 / SiliconFlow など）をすべてサポート。テキスト生成と画像解析で別々のプロバイダーを指定可能。各プロバイダーでプロキシモード（直接 / システムプロキシ / カスタムプロキシ）を個別設定可能。
2. **キャラクター写真の AI 分析**：写真をアップロードし、画像モデルで外見と性格を自動分析して小説に使えるキャラクターカードを生成。外見・性格・背景・補足はすべて手動編集してから保存できます。
3. **キャラクター関係の設定**：複数キャラクターとキャラクター間の関係タイプ・説明。
4. **執筆スタイルと参考テキスト**：参考小説の抜粋を貼り付けてスタイルを自動抽出、または手動で説明。グローバル前置プロンプトに対応。
5. **章の推敲・拡張**：章を編集中に任意のテキストを選択して推敲・拡張でき、結果はリアルタイムで本文に置き換わります。
6. **アウトライン編集**：アウトライン生成後、章のタイトルと概要を自由に編集可能。
7. **リアルタイムストリーミング**：章の生成・推敲・拡張はすべてリアルタイムで出力され、ローディングオーバーレイと進捗表示付き。
8. **完結 / 再開**：完結した小説は編集不可。いつでも「再開」して編集を再開できます。
9. **ゴミ箱**：削除した小説はまずゴミ箱に入り、復元または完全削除できます。
10. **一覧管理**：小説一覧はページネーション、執筆モード（即興 / アウトライン / 会話）での絞り込み、時間・タイトルでの並べ替え、モデル・ステータスでのフィルタリングに対応。
11. **リクエストログ**：すべての AI リクエストを記録し、ページ上で照会できます。

### 会話モードの詳細

- ユーザーと AI が IM チャット形式でストーリーを進行。AI は毎ターン500字以内の本文断片を出力します。
- 各メッセージは「編集」可能：AI が返した内容の編集はテキストの修正のみ（AI 呼び出しなし）。ユーザーの発言を編集した場合は AI の返信を再生成します。
- 任意の AI メッセージの後に「章を生成」：これまでの AI 出力を直接1つの正式な章に統合します（本文は再生成せず、要約のみ抽出）。
- 章に統合済みの会話はチャット領域から自動的に削除され、以降の統合に統合済みの内容は含まれません。
- 生成済みの章は閲覧・編集・削除できます。

## インストールと実行

### 必要環境

- Python 3.10 以上
- OpenAI 互換の AI プロバイダーアカウント（テキスト生成用。画像解析には画像入力対応モデルが必要）

### ワンクリックインストール（推奨）

```bash
cd novel-generator
bash install.sh
```

スクリプトは自動で：Python 仮想環境（`.venv`）の作成 → `requirements.txt` の依存関係インストール → SQLite データベース（`data/novel.db` と全テーブル）の初期化 → 起動スクリプト `run.sh` の生成を行います。

ポート・外部アクセスのカスタマイズ：

```bash
PORT=9000 HOST=0.0.0.0 bash install.sh
```

### サービスの起動

```bash
./run.sh                 # フォアグラウンド実行（デフォルト http://127.0.0.1:8000）
./run.sh --reload        # 開発モード（コード変更を自動リロード）
```

ブラウザで http://127.0.0.1:8000 を開きます（初回利用時にアクセスパスワードの設定を求められます）。

### 手動インストール

```bash
cd novel-generator
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

> データベース `data/novel.db` と全テーブルは初回起動時に自動で作成されるため、手動でのデータベース構築は不要です。

## 初回セットアップ

1. **「API 設定」→ プロバイダーを追加**：base_url + API Key + プロキシモードを入力して保存。
2. プロバイダーカードの **「🔌 接続」** をクリックして、そのプロバイダーのモデル一覧を取得。
3. **「＋ モデルを追加」** をクリック：モデル名を選択（接続後のドロップダウンから、または手入力）、タイプ（テキスト / 画像）を選択、必要に応じて temperature と max_tokens を設定（空欄はグローバル既定値）、保存。
4. モデル項目の **「●テキスト」「●画像」** をクリックして、テキスト生成 / 画像解析に使うモデルを指定（それぞれ1つのみ）。
5. **「小説作成」→「＋ 新規小説」** をクリックし、ウィザードに従って：
   - ① 基本情報：タイトル、ジャンル、執筆モード（アウトライン / 即興 / 会話）、章数、1章の文字数、執筆スタイル、参考テキスト、前置プロンプト。
   - ② キャラクター設定：写真をアップロードして AI で外見・性格を分析（または手入力）、人間関係を設定。
   - ③ 選択したモードで執筆開始：アウトライン生成 → 章ごとの執筆 / 即興執筆 / 会話創作。
6. 完了後、小説を「完結」させたり、Markdown をエクスポートしたり、全文を閲覧できます。

## 主要プロバイダーの base_url

| プロバイダー | base_url | モデル例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o`（画像対応） |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`（画像非対応） |
| 智譜 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` / `glm-4v`（画像対応） |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| 通義千問 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-vl-plus`（画像対応） |
| SiliconFlow | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` など |

> 注意：画像解析には画像入力対応モデルが必要です。多くのテキスト専用プロバイダー（例：DeepSeek のメインモデル）は画像非対応のため、その場合は「画像解析」用に画像対応のプロバイダー / モデルを別途指定してください。

## プロキシについて

`http_proxy` / `all_proxy` 環境変数が設定されている場合、openai SDK が自動的に読み取ります。国内プロバイダー（DeepSeek / 智譜 / Kimi）は「直接」を、OpenAI などは「システムプロキシ」または「カスタムプロキシ」を選び、ローカルプロキシアドレス（例：`http://127.0.0.1:4780`）を入力してください。

```
novel-generator/

├── uploads/          # アップロードされたキャラクター写真
├── output/           # エクスポートされた Markdown
└── static/           # フロントエンド（HTML/CSS/JS）
```

## 生成の仕組み

1. **アウトライン生成**：参考テキストのスタイルを分析 → キャラクター / 関係 / スタイルを集約 → あらすじ + 世界観 + 章立てを生成。
2. **章ごとの生成**：各章に完全な設定 + アウトライン + 前情提要を注入して一貫性を確保。各章生成後に前情提要を更新し、長すぎる場合は自動で要約。
3. **会話モード**：毎ターン、完全な設定 + 前情提要 + 会話履歴をプロンプトに注入し、AI が500字以内の本文断片を出力。
4. **文字数制御**：プロンプトと max_tokens の二重制約（`token_ratio` 係数は調整可能）。
5. **コンテキスト長**：モデルのコンテキスト長を設定でき、生成時に送信する内容量を自動制御します。
