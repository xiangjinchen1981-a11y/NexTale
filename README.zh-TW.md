# 織敘-NexTale

> [简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md)

一個基於 Python + Web 介面的 AI 小說創作工具。支援多種創作模式（大綱式 / 即興互動式 / 對話式）、多 AI 服務商接入、人物照片裁剪與 AI 分析、世界書與題材庫、提示詞配置、章節潤色擴寫、章節版本歷史、多格式匯出、完結管理、垃圾箱等完整的小說創作工作流程。

## 功能特性

### 多種創作模式

| 模式 | 說明 |
|------|------|
| **大綱式** | 先生成故事梗概、世界觀與章節大綱，再逐章生成正文，適合長篇規劃。 |
| **即興互動式** | 無需大綱，邊寫邊定，每次按「寫作指引」生成一章，適合靈感驅動。 |
| **對話模式** | 像 IM 聊天一樣推進劇情，AI 每次輸出一段正文片段（字數可自訂，預設 500 字），可隨時把對話合併成正式章節。 |
| **改寫模式** | 匯入已有小說原文，按你指定的要求（人稱、文風、篇幅、時代背景等）逐章改寫。 |
| **續寫模式** | 匯入已有小說原文，AI 自動結構化拆解原著（人物檔案 / 世界觀 / 主線框架 / 脈絡摘要）後，嚴格繼承原設定續寫後續章節。 |

### 核心能力

1. **多服務商接入**：支援所有 OpenAI 相容介面（OpenAI / DeepSeek / 智譜 GLM / Kimi / 通義千問 / 矽基流動等），文字生成與視覺分析可分別指定不同服務商；每個服務商可單獨設定代理模式（直連 / 系統代理 / 自訂代理）。
2. **人物照片裁剪與 AI 分析**：上傳照片後可在前端選擇框裁剪（純前端 canvas，無第三方函式庫）；AI 分析改為手動觸發，點「AI 分析」按鈕用視覺模型分析外貌與性格，生成可直接用於小說的角色卡；外貌/性格/背景/補充均可人工編輯後儲存。
3. **角色庫與多小說重用**：角色庫獨立成頂級標籤頁（列表 / 添加 / 詳情三頁），可按「小說名稱」篩選角色（選擇框 400px、預設展示最新 20 個、按需載入）；一個角色可同時屬於多部小說——建立小說時既可從角色庫勾選已有角色，也可新建角色；支援角色間關係類型與描述。
4. **寫作風格與參考文字**：可貼上參考小說片段自動提煉風格，也可手動描述；支援設定全域前置提示詞。
5. **章節潤色與擴寫**：編輯章節時，可選中任意文字片段進行潤色或擴寫，結果即時替換回正文。
6. **大綱編輯**：大綱生成後可自由編輯修改章節標題與概要。
7. **即時串流生成**：每章生成、潤色、擴寫均即時串流輸出，帶進度遮罩與遮罩提示。
8. **完結/重開**：完結後的小說不可再修改；可隨時「重開」恢復編輯。
9. **垃圾箱**：刪除的小說先進垃圾箱，可恢復或徹底刪除。
10. **列表管理**：小說列表支援分頁、按創作模式篩選、按時間/標題排序、按模型/狀態過濾。
11. **請求日誌**：記錄每次 AI 請求日誌，可在頁面查詢。
12. **世界書（Worldbook）**：可自建或匯入 SillyTavern 格式世界書，條目支援恆常注入與關鍵詞動態觸發（觸發詞 / 選擇性 / 機率），生成時自動匹配注入上下文。
13. **題材庫**：常用題材可儲存為模板（風格、參考文字、描述），支援批次匯入，新建小說時一鍵套用。
14. **提示詞配置**：所有 AI 提示詞（分析 / 大綱 / 章節 / 潤色 / 擴寫 / 對話 / 改寫 / 續寫 / 原著拆解）集中管理，可在「設定 → 提示詞」頁自訂並持久化覆蓋。
15. **章節版本歷史**：編輯或 AI 生成前自動快照章節，可查看歷史版本並一鍵回退。
16. **多格式匯出**：完結小說可匯出 Markdown / TXT / EPUB 三種格式。
17. **原著結構化拆解**：續寫/改寫模式匯入原文後，AI 自動提取人物檔案、世界觀、主線框架、伏筆清單與脈絡摘要；超長原文自動分塊拆解再合併。

### 對話模式詳解

- 使用者與 AI 以 IM 聊天方式交替推進劇情，AI 每次輸出一段不超過 500 字的正文片段。
- 每條訊息可「編輯」：編輯 AI 返回內容僅修改文字，不重新呼叫 AI；編輯使用者發言則重新生成 AI 回覆。
- 任意 AI 訊息後可「生成章節」：把之前的 AI 輸出直接合併成一個正式章節（正文不重新生成，僅提取摘要）。
- 已合併成章節的對話會自動從對話區移除，後續合併不再帶上已合併內容。
- 已生成章節可查看、編輯、刪除。

### 世界書與動態觸發

世界書用於存放作品的世界觀細節、角色背景、專有名詞等設定條目。每個條目可配置：

- **恆常注入**：`constant` 條目無條件加入每次生成的上下文。
- **動態觸發**：非恆常條目按 SillyTavern 風格的關鍵詞匹配——當觸發詞（`key`）出現在當前正文/梗概中時自動注入；`selective` 條目需主詞與次詞同時命中；`probability` 控制命中後的注入機率。
- **SillyTavern 匯入**：支援匯入 SillyTavern 世界書 JSON（entries 為物件或陣列均可），自動規範化觸發詞、位置、機率等欄位。

### 世界觀來源保護

若你在「世界觀設定」中手動填寫了內容，AI 生成大綱時不會覆蓋它；只有留空時才會由 AI 自動生成世界觀。

## 安裝與執行

### 環境要求

- Python 3.10 及以上
- 一個 OpenAI 相容的 AI 服務商帳號（用於文字生成；視覺分析需支援圖片輸入的模型）

### 一鍵安裝（推薦）

```bash
cd novel-generator
bash install.sh
```

腳本會自動完成：建立 Python 虛擬環境（`.venv`）→ 安裝 `requirements.txt` 依賴 → 初始化 SQLite 資料庫（`data/novel.db` 及全部資料表）→ 生成啟動腳本 `run.sh`。

自訂監聽連接埠 / 對外存取：

```bash
PORT=9000 HOST=0.0.0.0 bash install.sh
```

### 啟動服務

```bash
./run.sh                 # 前景執行（預設 http://127.0.0.1:8000）
./run.sh --reload        # 開發模式（程式碼變更自動熱重載）
```

瀏覽器開啟 http://127.0.0.1:8000（首次使用會提示設定存取密碼）。

### 手動安裝

```bash
cd novel-generator
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

> 資料庫 `data/novel.db` 及所有資料表會在首次啟動時自動建立，無需手動建庫。

## 首次使用步驟

1. **「設定」→「大模型API」→ 新增服務商**：填 base_url + API Key + 代理模式，儲存。
2. 在服務商卡片上點 **「🔌 連接」**，拉取該服務商的模型列表。
3. 點 **「＋ 新增模型」**：選模型名（連接後從下拉選單選擇，也可手輸）、選類型（文字 / 視覺）、可配 temperature 與 max_tokens（留空用全域預設），儲存。
4. 在模型條目上點 **「●文字」「●視覺」**，指定目前文字生成 / 視覺分析用哪個模型（各只能選一個）。
5. 可選（進階）：
   - **「題材庫」**：預存常用題材模板（風格 / 參考文字 / 描述），新建小說時一鍵套用。
   - **「世界書」**：自建或匯入 SillyTavern 世界書，存放世界觀細節與專有名詞設定。
   - **「設定 → 提示詞」**：自訂各類 AI 提示詞，覆蓋預設模板。
6. **「小說創作」→ 點「＋ 新建小說」**，按精靈完成（步驟可點擊跳轉，每步可獨立儲存）：
   - ① 基本資訊：標題、題材（可從題材庫選擇）、創作模式（大綱/即興/對話/改寫/續寫）、章節數、每章字數、寫作風格、參考文字、原文匯入（改寫/續寫）。
   - ② 角色設定：從角色庫勾選已有角色（一個角色可屬於多部小說）或新建角色、上傳照片（可裁剪）手動觸發 AI 分析外貌性格，設定人物關係。
   - ③ 模型與提示詞：選擇本小說使用的創作模型、填寫全域前置提示詞。
7. 完成後按創作模式進入對應寫作頁（生成大綱 → 逐章生成 / 即興寫作 / 對話創作 / 改寫 / 續寫）。
8. 完成後可「完結」小說，匯出 Markdown / TXT / EPUB 或查看全文。

## 常見服務商 base_url

| 服務商 | base_url | 模型範例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o`（支援視覺） |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`（無視覺） |
| 智譜 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` / `glm-4v`（視覺） |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| 通義千問 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-vl-plus`（視覺） |
| 矽基流動 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` 等 |

> 注意：視覺分析需要一個支援圖片輸入的模型。很多純文字服務商（如 DeepSeek 主模型）不支援視覺，此時請為「視覺分析」單獨指定一個支援視覺的服務商/模型。

## 代理說明

本機若設定了 `http_proxy` / `all_proxy` 環境變數，openai SDK 會自動讀取。國內服務商（DeepSeek / 智譜 / Kimi）應選「直連」，OpenAI 等需選「系統代理」或「自訂代理」並填入本機代理位址（如 `http://127.0.0.1:4780`）。

```
├── run.sh            # 啟動腳本（由 install.sh 生成）

├── output/           # 匯出的 Markdown/TXT/EPUB
└── static/           # 前端頁面（HTML/CSS/JS）
```

## 生成原理

1. **生成大綱**：先分析參考文字風格 → 彙總角色/關係/風格 → 生成故事梗概 + 世界觀 + 章節大綱；若使用者手動填寫過世界觀則保留不覆蓋。
2. **逐章生成**：每章注入完整設定 + 大綱 + 前情提要，保證連貫性；每章生成後自動更新前情提要，過長時自動濃縮。
3. **對話模式**：每輪把完整設定 + 前情提要 + 對話歷史注入 prompt，AI 輸出一段劇情片段，字數由作者指定（預設 500 字左右）。
4. **世界書注入**：生成大綱/章節/對話時，恆常條目無條件注入，非恆常條目按觸發詞匹配動態注入。
5. **字數控制**：透過提示詞 + max_tokens 雙重約束（`token_ratio` 係數可調）。
6. **上下文長度**：可設定模型的上下文長度（context length），生成時自動控制傳入內容規模。
