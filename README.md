# 织叙-NexTale

> [简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md)

一个基于 Python + Web 界面的 AI 小说创作工具。支持多种创作模式（大纲式 / 即兴交互式 / 对话式）、多 AI 服务商接入、人物照片裁剪与 AI 分析、世界书与题材库、提示词配置、章节润色扩写、章节版本历史、多格式导出、完结管理、垃圾箱等完整的小说创作工作流。

## 功能特性

### 多种创作模式

| 模式 | 说明 |
|------|------|
| **大纲式** | 先生成故事梗概、世界观与章节大纲，再逐章生成正文，适合长篇规划。 |
| **即兴交互式** | 无需大纲，边写边定，每次按「写作指引」生成一章，适合灵感驱动。 |
| **对话模式** | 像 IM 聊天一样推进剧情，AI 每次输出不超过 500 字，可随时把对话合并成正式章节。 |

### 核心能力

1. **多服务商接入**：支持所有 OpenAI 兼容接口（OpenAI / DeepSeek / 智谱 GLM / Kimi / 通义千问 / 硅基流动等），文本生成与视觉分析可分别指定不同服务商；每个服务商可单独设置代理模式（直连 / 系统代理 / 自定义代理）。
2. **人物照片裁剪与 AI 分析**：上传照片后可在前端选择框裁剪（纯前端 canvas，无第三方库）；AI 分析改为手动触发，点「AI 分析」按钮用视觉模型分析外貌与性格，生成可直接用于小说的角色卡；外貌/性格/背景/补充均可人工编辑后保存。
3. **角色库与关系设定**：角色库独立成顶级标签页（列表 / 添加 / 详情三页），可集中维护角色，新建小说时复用；支持多角色 + 角色间关系类型与描述。
4. **写作风格与参考文本**：可粘贴参考小说片段自动提炼风格，也可手动描述；支持设置全局前置提示词。
5. **章节润色与扩写**：编辑章节时，可选中任意文字片段进行润色或扩写，结果实时替换回正文。
6. **大纲编辑**：大纲生成后可自由编辑修改章节标题与概要。
7. **实时流式生成**：每章生成、润色、扩写均实时流式输出，带进度遮罩与遮罩提示。
8. **完结/重开**：完结后的小说不可再修改；可随时「重开」恢复编辑。
9. **垃圾箱**：删除的小说先进垃圾箱，可恢复或彻底删除。
10. **列表管理**：小说列表支持分页、按创作模式（即兴/大纲/对话）筛选、按时间/标题排序、按模型/状态过滤。
11. **请求日志**：记录每次 AI 请求日志，可在页面查询。
12. **世界书（Worldbook）**：可自建或导入 SillyTavern 格式世界书，条目支持恒常注入与关键词动态触发（触发词 / 选择性 / 概率），生成时自动匹配注入上下文。
13. **题材库**：常用题材可保存为模板（风格、参考文本、描述），支持批量导入，新建小说时一键套用。
14. **提示词配置**：所有 AI 提示词（分析 / 大纲 / 章节 / 润色 / 扩写 / 对话）集中管理，可在页面自定义并持久化覆盖。
15. **章节版本历史**：编辑或 AI 生成前自动快照章节，可查看历史版本并一键回退。
16. **多格式导出**：完结小说可导出 Markdown / TXT / EPUB 三种格式。

### 对话模式详解

- 用户与 AI 以 IM 聊天方式交替推进剧情，AI 每次输出一段不超过 500 字的正文片段。
- 每条消息可「编辑」：编辑 AI 返回内容仅修改文本，不重新调用 AI；编辑用户发言则重新生成 AI 回复。
- 任意 AI 消息后可「生成章节」：把之前的 AI 输出直接合并成一个正式章节（正文不重新生成，仅提取摘要）。
- 已合并成章节的对话会自动从对话区移除，后续合并不再带上已合并内容。
- 已生成章节可查看、编辑、删除。

### 世界书与动态触发

世界书用于存放作品的世界观细节、角色背景、专有名词等设定条目。每个条目可配置：

- **恒常注入**：`constant` 条目无条件加入每次生成的上下文。
- **动态触发**：非恒常条目按 SillyTavern 风格的关键词匹配——当触发词（`key`）出现在当前正文/梗概中时自动注入；`selective` 条目需主词与次词同时命中；`probability` 控制命中后的注入概率。
- **SillyTavern 导入**：支持导入 SillyTavern 世界书 JSON（entries 为对象或数组均可），自动规范化触发词、位置、概率等字段。

### 世界观来源保护

若你在「世界观设定」中手动填写了内容，AI 生成大纲时不会覆盖它；只有留空时才会由 AI 自动生成世界观。

## 安装与运行

### 环境要求

- Python 3.10 及以上
- 一个 OpenAI 兼容的 AI 服务商账号（用于文本生成；视觉分析需支持图片输入的模型）

### 一键安装（推荐）

```bash
cd novel-generator
bash install.sh
```

脚本会自动完成：创建 Python 虚拟环境（`.venv`）→ 安装 `requirements.txt` 依赖 → 初始化 SQLite 数据库（`data/novel.db` 及全部表）→ 生成启动脚本 `run.sh`。

自定义监听端口 / 对外访问：

```bash
PORT=9000 HOST=0.0.0.0 bash install.sh
```

### 启动服务

```bash
./run.sh                 # 前台运行（默认 http://127.0.0.1:8000）
./run.sh --reload        # 开发模式（代码改动自动热重载）
```

浏览器打开 http://127.0.0.1:8000（首次使用会提示设置访问密码）。

### 手动安装

```bash
cd novel-generator
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000
```

> 数据库 `data/novel.db` 及所有表会在首次启动时自动创建，无需手动建库。

## 首次使用步骤

1. **「API 配置」→ 添加服务商**：填 base_url + API Key + 代理模式，保存。
2. 在服务商卡片上点 **「🔌 连接」**，拉取该服务商的模型列表。
3. 点 **「＋ 添加模型」**：选模型名（连接后从下拉选择，也可手输）、选类型（文本 / 视觉）、可配 temperature 与 max_tokens（留空用全局默认），保存。
4. 在模型条目上点 **「●文本」「●视觉」**，指定当前文本生成 / 视觉分析用哪个模型（各只能选一个）。
5. 可选（进阶）：
   - **「题材库」**：预存常用题材模板（风格 / 参考文本 / 描述），新建小说时一键套用。
   - **「世界书」**：自建或导入 SillyTavern 世界书，存放世界观细节与专有名词设定。
   - **「提示词配置」**：自定义各类 AI 提示词，覆盖默认模板。
6. **「小说创作」→ 点「＋ 新建小说」**，按向导完成：
   - ① 基本信息：标题、题材（可从题材库选择）、创作模式（大纲/即兴/对话）、章节数、每章字数、写作风格、参考文本、前置提示词。
   - ② 角色设定：从角色库选择或上传照片（可裁剪）手动触发 AI 分析外貌性格，设定人物关系。
   - ③ 进入对应创作模式开始写作：生成大纲 → 逐章生成 / 即兴写作 / 对话创作。
7. 完成后可「完结」小说，导出 Markdown / TXT / EPUB 或查看全文。

## 常见服务商 base_url

| 服务商 | base_url | 模型示例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o`（支持视觉） |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`（无视觉） |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` / `glm-4v`（视觉） |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` / `qwen-vl-plus`（视觉） |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` 等 |

> 注意：视觉分析需要一个支持图片输入的模型。很多纯文本服务商（如 DeepSeek 主模型）不支持视觉，此时请为「视觉分析」单独指定一个支持视觉的服务商/模型。

## 代理说明

本机若设置了 `http_proxy` / `all_proxy` 环境变量，openai SDK 会自动读取。国内服务商（DeepSeek / 智谱 / Kimi）应选「直连」，OpenAI 等需选「系统代理」或「自定义代理」并填入本地代理地址（如 `http://127.0.0.1:4780`）。

## 生成原理

1. **生成大纲**：先分析参考文本风格 → 汇总角色/关系/风格 → 生成故事梗概 + 世界观 + 章节大纲；若用户手动填写过世界观则保留不覆盖。
2. **逐章生成**：每章注入完整设定 + 大纲 + 前情提要，保证连贯性；每章生成后自动更新前情提要，过长时自动浓缩。
3. **对话模式**：每轮把完整设定 + 前情提要 + 对话历史注入 prompt，AI 输出不超过 500 字的剧情片段。
4. **世界书注入**：生成大纲/章节/对话时，恒常条目无条件注入，非恒常条目按触发词匹配动态注入。
5. **字数控制**：通过提示词 + max_tokens 双重约束（`token_ratio` 系数可调）。
6. **上下文长度**：可设置模型的上下文长度（context length），生成时自动控制传入内容规模。
